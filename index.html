Install on Android TV

A ten-foot remote-first build of the same player — leanback launcher, D-pad everywhere, fullscreen zap.

  1. Download the APK

    Grab NusaTV-AndroidTV-v0.1.0.apk from the releases page onto a USB stick or download it directly on the TV's browser.

  2. Allow unknown apps

    Settings → Device Preferences → Security & Restrictions → Unknown sources, then enable your file manager.

  3. Install & tune

    Open the APK from the file manager, install, and launch NusaTV from the TV launcher. First channel plays on OK.
